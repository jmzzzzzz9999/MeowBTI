## 系列猫咪形象设定

这些猫咪形象是 MeowBTI 的视觉阵营设定，用来帮助用户快速识别系列气质；它们不代表真实品种或毛色必然对应某种性格。

| 系列 | 建议猫咪形象 | 视觉关键词 |
|---|---|---|
| 亲和系 | 橘白猫 / 金渐层 | 圆脸、眼神柔软、暖色系、姿态主动亲近，整体要有讨人喜欢的亲和感 |
| 潜行系 | 黑猫 | 轮廓轻、眼睛亮、低调深色、姿态偏侧身或半隐藏，强调“暗中存在” |
| 探索系 | 虎斑猫 | 线条灵活、运动感强、条纹明显、姿态有跳跃、捕猎或研究感 |
| 主权系 | 黑白猫 | 黑白对比强、轮廓清楚、气场足，姿态稳定或带管理感 |
| 安定系 | 长毛蓝猫 / 长毛蓝灰猫 | 身体更圆、更沉静、毛感柔软蓬松，姿态放松舒适 |
