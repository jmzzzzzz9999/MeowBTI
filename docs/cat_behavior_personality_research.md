# 猫咪行为学与人格映射调研文档

更新时间：2026-05-25  
用途：为 “MeowBTI / 猫咪人格测试” 的题目设计、人格设定、结果解释提供科学底座与产品化表达框架。

## 1. 核心结论

猫咪性格不能简单等同于人类性格，但可以借用人类人格模型的语言做“可理解的翻译”。比较稳妥的做法是：底层使用猫行为学和猫性格研究维度，表层再转译成 MBTI/SBTI 式的有趣人格设定。

建议采用三层结构：

1. **行为层**：猫实际表现出来的动作、姿态、互动方式，例如躲藏、蹭人、尾巴甩动、攻击、跟随、夜间活动、玩耍、叫声。
2. **心理倾向层**：从行为推断出的稳定倾向，例如安全感、探索欲、社交需求、边界感、冲动性、领地意识。
3. **人格表达层**：给用户看的类型设定，例如“家庭董事长猫”“社交保安猫”“罐罐提款猫”“暗中观察猫”。

重要边界：

- 猫的行为高度受环境、健康、年龄、绝育状态、早期社会化、多猫关系影响。
- 品种可能有统计倾向，但不能把品种当作个体性格判决。
- 突然出现的攻击、躲藏、乱尿、过度舔毛、叫声变化，首先应考虑健康或压力问题，而不是直接解释为“性格如此”。
- 测评结果适合做娱乐化人格画像，不适合作为诊断、训练惩罚或医疗建议。

## 2. 猫行为学基础

### 2.1 猫是“独居捕猎者 + 弹性社交者”

猫的祖先生态决定了它们与狗、人类有明显差异。它们是小型捕食者，同时也是可能被更大动物威胁的动物。因此猫的行为系统里同时存在：

- **捕猎驱动**：追逐、扑咬、伏击、夜间活动、对小动静高度敏感。
- **安全驱动**：躲高处、藏起来、谨慎接近陌生人或新物品。
- **领地驱动**：依赖熟悉气味、固定路线、资源位置和安全区域。
- **选择性交互**：猫可以形成社会关系，但更需要自主选择互动的距离、时机和强度。

Merck Veterinary Manual 总结，猫大多是独自捕猎者，强烈受气味影响，会通过尿液喷洒、粪便、抓挠、脸颊或身体摩擦来标记环境或其他猫。AAFP/ISFM 2022 猫友好互动指南也强调，猫需要控制感、安全感、选择权和熟悉感。

产品启发：

- 猫咪性格题目不应只问“黏不黏人”，还要问“它是否需要控制互动节奏”。
- 很多看似高冷的行为，本质上可能是安全感管理，而不是不喜欢人。

参考：

- [Merck Veterinary Manual: Social Behavior of Cats](https://www.merckvetmanual.com/en-us/veterinary/behavior/behavior-of-cats/social-behavior-of-cats)
- [2022 AAFP/ISFM Cat Friendly Veterinary Interaction Guidelines](https://pmc.ncbi.nlm.nih.gov/articles/PMC10845437/)

### 2.2 健康猫环境的五大支柱

AAFP/ISFM 的猫环境需求指南提出了健康猫环境的五个核心支柱：

1. 提供安全地点。
2. 提供多个且分散的关键资源，包括食物、水、猫砂盆、抓挠处、休息区、玩耍区。
3. 提供玩耍和捕猎行为机会。
4. 提供正向、稳定、可预测的人猫互动。
5. 尊重猫的嗅觉重要性。

这些支柱说明：猫的很多“性格表现”其实是环境是否满足需求的结果。

例子：

- 一只“易怒猫”可能只是缺少退路、垂直空间或稳定资源。
- 一只“夜间蹦迪猫”可能是白天猎物模拟和能量释放不足。
- 一只“乱抓猫”不是故意破坏，而是在做正常抓挠标记。

参考：

- [AAFP and ISFM Feline Environmental Needs Guidelines](https://journals.sagepub.com/doi/full/10.1177/1098612x13477537)
- [PMC 全文备份](https://pmc.ncbi.nlm.nih.gov/articles/PMC11383066/)

## 3. 猫咪身体语言与行为信号

解读猫行为时，应看“组合信号”，不要只看单一动作。比如呼噜可能代表舒适，也可能是疼痛、压力或自我安抚；尾巴竖起多为友好，但如果同时炸毛、拱背，就可能是高度激动或威胁。

### 3.1 尾巴

| 行为/姿态 | 常见含义 | 测评可问方向 |
|---|---|---|
| 尾巴竖起，身体放松 | 友好、自信、打招呼 | 对人社交、亲近度 |
| 尾尖轻轻弯曲或抖动 | 期待、兴奋、愉悦 | 兴奋阈值、互动期待 |
| 快速甩尾、拍尾 | 烦躁、过度刺激、专注猎物 | 边界感、耐受度 |
| 尾巴夹低或贴身 | 害怕、防御、不安 | 恐惧性、安全需求 |
| 炸毛 | 高度惊吓、防御、威慑 | 应激反应 |

### 3.2 耳朵

| 行为/姿态 | 常见含义 | 测评可问方向 |
|---|---|---|
| 耳朵自然向前 | 好奇、放松、关注 | 探索欲 |
| 耳朵左右转动 | 监测环境、警觉 | 警觉性 |
| 飞机耳/侧压 | 犹豫、紧张、不确定 | 谨慎度 |
| 耳朵贴后或压平 | 恐惧、防御、可能攻击 | 防御性、应激 |

### 3.3 眼睛与面部

| 行为/姿态 | 常见含义 | 测评可问方向 |
|---|---|---|
| 慢眨眼 | 信任、放松、友好 | 信任建立速度 |
| 瞳孔放大 | 兴奋、恐惧、玩耍、弱光 | 激活水平 |
| 长时间凝视 | 警戒、挑战、捕猎关注 | 支配/警觉 |
| 胡须自然向外 | 放松或兴趣 | 情绪稳定 |
| 胡须向后贴 | 紧张、防御 | 压力敏感 |

### 3.4 身体姿态

| 行为/姿态 | 常见含义 | 测评可问方向 |
|---|---|---|
| 露肚皮但不让摸 | 信任环境，但未必邀请触碰 | 边界感 |
| 趴低、缩成一团 | 害怕、疼痛、保守观察 | 安全感 |
| 拱背炸毛 | 防御性威慑 | 应激强度 |
| 蹭人、头顶人 | 气味标记、亲近、社交绑定 | 依恋和亲人度 |
| 踩奶 | 舒适、幼年行为延续，也可能自我安抚 | 放松方式 |

### 3.5 声音

| 声音 | 常见含义 | 测评可问方向 |
|---|---|---|
| 喵叫 | 对人沟通、需求表达、问候、抗议 | 表达欲 |
| 呼噜 | 舒适，也可能疼痛/压力下自我安抚 | 情绪状态需结合姿态 |
| 咕噜/颤音 | 友好招呼、兴奋 | 社交积极性 |
| 嘶嘶声 | 警告、防御、害怕 | 边界警告 |
| 低吼 | 强烈不适、威胁、防御 | 攻击风险 |

## 4. 猫咪性格研究：可用的科学维度

### 4.1 Feline Five：猫咪五大人格

2017 年 PLOS ONE 发表的 “Feline Five” 研究使用 2802 只猫的数据，提出了五个猫咪人格因子：

| 维度 | 高分表现 | 低分表现 | 可对应的人类人格语言 |
|---|---|---|---|
| 神经质 Neuroticism | 不安、害怕、谨慎、敏感、容易紧张 | 稳定、镇定、信任 | 情绪敏感度/安全感 |
| 支配性 Dominance | 对其他猫强势、欺负、竞争资源、易冲突 | 温和、让步、合作 | 领地权力感 |
| 冲动性 Impulsiveness | 行为难预测、鲁莽、忽然冲动 | 稳定、自控、可预测 | 自控力/秩序感 |
| 亲和性 Agreeableness | 亲人、温柔、友好、可合作 | 冷淡、攻击性高、难接近 | 友善度 |
| 外向性 Extraversion | 好奇、活跃、爱探索、爱玩 | 安静、保守、活动少 | 探索能量 |

这套模型非常适合做 MeowBTI 的底层维度，因为它天然可以和人类 Big Five 对应，但又保留了猫特有的“支配性”和“冲动性”。

参考：

- [The Feline Five: An exploration of personality in pet cats](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0183455)

### 4.2 赫尔辛基七维模型：性格 + 行为问题

2021 年 Scientific Reports 研究收集超过 4300 只猫的数据，提出七个猫咪行为与性格维度：

| 维度 | 含义 | 产品化解释 |
|---|---|---|
| Fearfulness 恐惧性 | 对陌生人、新环境、突发刺激的害怕程度 | 安全雷达 |
| Activity/Playfulness 活跃/玩耍 | 活动量、游戏欲、探索行为 | 电量条 |
| Aggression toward humans 对人攻击性 | 对人抓咬、威胁、防御 | 人类边界警告 |
| Sociability toward humans 对人社交性 | 接近人、喜欢互动、亲近人 | 人类亲和力 |
| Sociability toward cats 对猫社交性 | 与其他猫相处、共处、互动 | 同类社交力 |
| Excessive grooming 过度理毛 | 压力、皮肤问题或强迫样行为相关 | 压力外显 |
| Litterbox issues 猫砂盆问题 | 可能与健康、压力、砂盆偏好有关 | 环境适配警报 |

这套模型的优势是更贴近日常养猫问题。它提醒我们：测试里不应把“乱尿”“过度舔毛”当成搞笑人格，而要标成可能需要观察健康和环境的信号。

参考：

- [Reliability and Validity of Seven Feline Behavior and Personality Traits](https://pmc.ncbi.nlm.nih.gov/articles/PMC8300181/)

## 5. 品种、环境与个体差异

### 5.1 品种可能影响性格倾向，但不是命运

赫尔辛基研究发现，不同品种或品种组在七个行为/性格维度上存在显著差异。也就是说，品种可能与活跃度、恐惧性、社交性等有关。

但产品设计必须谨慎：

- 品种差异是群体统计，不代表个体必然。
- 很多猫是混血或收养猫，品种信息不准确。
- 年龄、绝育、健康、早期社会化、家庭环境、多猫关系，可能比品种更影响当下行为。

可用于测试的表达：

- “品种背景可能影响你的猫的默认气质，但它现在的行为更像是环境、经验和身体状态一起写出来的。”

### 5.2 早期社会化

猫幼年期对人、声音、物体、其他动物的接触，会影响成年后的恐惧性和社交舒适度。社会化不足的猫可能更谨慎、更容易躲藏或防御。

测试题目可问：

- 小时候是否经常接触不同人？
- 到新家后适应速度如何？
- 对陌生人是主动观察、靠近，还是立刻躲藏？

### 5.3 多猫家庭

多猫家庭里的行为必须看资源竞争：

- 食盆、水碗、猫砂盆、睡眠点、抓板是否足够并分散？
- 是否有一只猫堵门、堵猫砂盆、占高处？
- 是否有猫被迫改变活动路线？

一只猫看似“胆小”，可能是在多猫权力结构里被压制；一只猫看似“霸道”，可能是在控制关键资源。

参考：

- [Merck Veterinary Manual: Behavior Problems of Cats](https://www.merckvetmanual.com/behavior/behavior-of-cats/behavior-problems-of-cats)
- [AAFP/ISFM Environmental Needs Guidelines](https://journals.sagepub.com/doi/full/10.1177/1098612x13477537)

## 6. 用人类性格理解猫：映射框架

### 6.1 与 Big Five 的映射

人类 Big Five 与猫咪性格可以做近似映射，但要避免一一对应过度解释。

| 人类 Big Five | 猫咪可观察对应 | 说明 |
|---|---|---|
| 外向性 Extraversion | 活跃、好奇、探索、主动互动 | 猫的外向更多是探索和游戏，不一定等于爱社交 |
| 宜人性 Agreeableness | 温柔、亲人、少攻击、可合作 | 可对应亲和性和低攻击性 |
| 神经质 Neuroticism | 易紧张、怕生、应激、躲藏 | 可对应恐惧性和安全感需求 |
| 尽责性 Conscientiousness | 稳定、可预测、自控、规律 | 猫没有人类责任感，但可映射为自控和规律性 |
| 开放性 Openness | 对新玩具、新空间、新人好奇 | 与探索欲、玩耍、认知灵活性有关 |

### 6.2 与 MBTI 的映射

MBTI 是人类偏好模型，不能直接套到猫身上。但可以借其“二分维度”的可读性，做猫行为版本：

| 类 MBTI 维度 | 猫咪版本 | 高 A 表现 | 高 B 表现 |
|---|---|---|---|
| E/I | 外放互动 / 内收观察 | 主动迎接、跟人、叫人 | 远距离观察、慢热、自主 |
| S/N | 现实感官 / 新奇探索 | 重视气味、路线、固定资源 | 爱研究新物、开柜、试探 |
| T/F | 规则边界 / 情绪连接 | 明确拒绝、按自己节奏 | 贴贴、回应情绪、寻求陪伴 |
| J/P | 秩序规律 / 即兴随机 | 固定作息、固定路线 | 忽然疯跑、随机躺倒、突袭玩耍 |

注意：这里是娱乐化表达，不是标准 MBTI。

### 6.3 与人类依恋风格的映射

猫可以与人形成依恋关系。Current Biology 2019 年研究显示，猫在安全基地测试中表现出类似婴儿和狗的依恋模式。用于产品时，可以把猫对人的互动分为：

| 猫咪依恋倾向 | 表现 | 人类隐喻 |
|---|---|---|
| 安全型 | 人回来后恢复探索，愿意互动，也能独处 | “你在就安心，你不在我也能过” |
| 焦虑型 | 过度跟随、分离后强烈寻求关注 | “你去哪了，解释一下” |
| 回避型 | 不太寻求人类安慰，保持距离 | “我知道你回来了，但我正在独立” |
| 混合/矛盾型 | 想靠近又容易被触碰激怒 | “想贴，但别乱摸” |

参考：

- [Attachment bonds between domestic cats and humans, Current Biology](https://www.cell.com/current-biology/fulltext/S0960-9822(19)31086-3)

## 7. MeowBTI 建议维度

建议不要完全照搬 MBTI 四维，而是建立 8 个猫行为维度，再组合成类型。

### 7.1 八个核心维度

| 维度 | 低分端 | 高分端 | 题目观察点 |
|---|---|---|---|
| 亲人度 | 自主、慢热、保持距离 | 黏人、跟随、主动互动 | 是否迎接人、蹭人、上腿 |
| 探索欲 | 谨慎、固定路线 | 好奇、开箱、巡逻 | 新物品反应 |
| 安全敏感 | 稳定、抗惊吓 | 警觉、怕生、易躲 | 陌生人/声音/搬家 |
| 能量值 | 安静、低活动 | 活跃、疯跑、爱玩 | 夜间活动、游戏时长 |
| 边界感 | 容忍触摸 | 明确拒绝、易过载 | 摸肚子、抱起、梳毛 |
| 领地感 | 共享资源、少竞争 | 占点、堵路、标记 | 多猫资源关系 |
| 情绪稳定 | 可预测、恢复快 | 情绪波动、突然抓咬 | 过度刺激、攻击前信号 |
| 表达欲 | 安静、肢体表达 | 爱叫、会要求、会抗议 | 喵叫场景 |

### 7.2 可选风险提示维度

这些不建议做成“搞笑人格”，而是做成结果页提示：

| 行为 | 可能含义 | 结果页处理 |
|---|---|---|
| 突然乱尿/乱拉 | 泌尿、疼痛、压力、砂盆问题 | 建议观察并咨询兽医 |
| 过度舔毛 | 压力、皮肤问题、疼痛 | 标为健康/压力信号 |
| 突然攻击 | 疼痛、恐惧、过度刺激、环境冲突 | 不贴“坏脾气”标签 |
| 长期躲藏 | 恐惧、社会化不足、健康问题 | 关注安全空间与压力源 |
| 食欲/活动量变化 | 可能是健康问题 | 明确建议就医 |

## 8. 人格类型设定方向

类型名应当做到三件事：

1. 一眼能懂。
2. 有截图传播欲。
3. 不把异常行为污名化。

### 8.1 类型原型示例

| 类型名 | 底层维度 | 人格说明 |
|---|---|---|
| 家庭董事长猫 | 高领地感、高边界感、高稳定 | 家里所有路线和资源都在它的脑内地图里，人类只是租客 |
| 罐罐提款猫 | 高亲人度、高表达欲、高目标导向 | 亲人是真的，想吃也是真的，感情和需求可以同时成立 |
| 暗中观察猫 | 高安全敏感、低外放互动、高观察 | 不是不爱你，是需要先确认世界没有问题 |
| 社交保安猫 | 高支配性、高警觉、高同类控制 | 喜欢巡逻、管理门口、监督其他猫和人类动向 |
| 睡神哲学猫 | 低能量、高稳定、低表达 | 情绪稳定得像一块温热毛毯，人生主线是找最佳睡点 |
| 飞机耳艺术家 | 高敏感、高表达、高边界 | 情绪细腻，身体语言丰富，讨厌被粗暴读懂 |
| 开箱工程师猫 | 高探索、高能量、高开放 | 任何盒子、柜门、水杯都值得被研究 |
| 贴贴外交官猫 | 高亲人、高亲和、低攻击 | 擅长用蹭蹭和慢眨眼解决家庭关系 |
| 午夜蹦迪猫 | 高能量、高冲动、高玩耍 | 白天省电，晚上系统自动更新 |
| 人类训练师猫 | 高表达、高目标、高学习 | 很快学会如何让人类开门、添饭、让座 |

### 8.2 类型解释模板

每个类型建议包含：

- **一句话人格**：适合截图传播。
- **核心气质**：基于 2-3 个高分维度。
- **典型行为**：用用户熟悉的猫行为落地。
- **喜欢的相处方式**：给养猫建议。
- **容易被误解的点**：避免污名化。
- **注意信号**：如出现异常变化，应先排查健康和压力。

示例：

> 暗中观察猫：它不是不参与家庭生活，它是在担任气氛审计。新东西先不碰，新人先不理，等安全评估通过，它会用非常克制的方式把你纳入自己猫生地图。

## 9. 测评题目设计建议

### 9.1 题目原则

1. 问具体行为，不问抽象评价。
   - 弱：“你的猫外向吗？”
   - 强：“家里来陌生人时，它通常会怎么做？”

2. 一个维度至少 3-5 道题交叉验证。
   - 亲人度可从迎接、跟随、蹭人、睡觉距离、主动叫人等角度问。

3. 提供“看情况/不适用”选项。
   - 有些猫没有同类环境，有些猫不能外出，有些行为主人没观察过。

4. 区分长期稳定行为和突然变化。
   - 突然变化要进入风险提示，不进入人格评分。

5. 避免引导主人惩罚猫。
   - 对抓挠、夜间活动、攻击等，解释为需求或压力信号，而不是“坏”。

### 9.2 题目样例

#### 亲人度

家人回家时，你的猫最常见的反应是：

- 主动跑来、尾巴竖起、蹭人或叫人。
- 抬头确认一下，继续做自己的事。
- 躲远一点，等一会儿再出来。
- 反应不固定，看当天心情。

#### 探索欲

家里出现一个新纸箱或新袋子，它通常会：

- 立刻钻进去研究。
- 先闻一闻，确认安全后再玩。
- 远远观察很久。
- 完全没兴趣。

#### 边界感

当人类摸它不想被摸的部位时，它通常会：

- 直接走开。
- 甩尾、飞机耳、回头看，先警告。
- 轻咬或拍一下。
- 大多数时候都能接受。

#### 安全敏感

突然有很大声音时，它通常会：

- 迅速躲起来，过很久才出来。
- 警觉观察，但能较快恢复。
- 被吓一下，很快继续玩。
- 甚至要去看看发生了什么。

#### 表达欲

它最常用什么方式向人类提出要求？

- 喵喵叫，直到你理解。
- 蹭腿、带路、盯着你。
- 直接坐到目标物旁边。
- 很少主动表达。

#### 能量值

一天中，它最像哪种状态？

- 每天固定疯跑和捕猎游戏。
- 有玩耍需求，但时间不长。
- 大部分时间睡觉或安静观察。
- 能量波动很大，无法预测。

### 9.3 评分建议

可以使用 1-5 分 Likert 量表，也可以使用多选场景题。娱乐产品更适合多选场景题，因为更有画面感。

推荐：

- 每题影响 1-2 个维度。
- 每个选项给不同维度加权。
- 结果不只看最高维度，而看组合模式。
- 结果页显示 3 个最高特质 + 1 个隐藏特质 + 1 个相处建议。

示例：

| 选项 | 亲人度 | 安全敏感 | 探索欲 | 边界感 |
|---|---:|---:|---:|---:|
| 主动跑来蹭人 | +2 | -1 | 0 | 0 |
| 抬头确认继续睡 | 0 | 0 | -1 | +1 |
| 躲远观察 | -1 | +2 | -1 | +1 |
| 看当天心情 | 0 | +1 | 0 | +1 |

## 10. 结果页表达规范

### 10.1 应该做

- 用可爱的语言描述猫的“策略”，而不是道德评价。
- 把行为放回猫的需求：安全、选择、领地、玩耍、嗅觉、资源。
- 给出相处建议：更好的玩耍、触摸边界、资源摆放、慢引入新刺激。
- 允许同一只猫有矛盾性：又黏人又边界强、又胆小又好奇。

### 10.2 不应该做

- 不说“你的猫坏、疯、讨厌你”。
- 不把攻击、乱尿、过度舔毛做成纯搞笑标签。
- 不用结果替代兽医判断。
- 不把品种刻板印象当作准确结论。

## 11. 推荐的信息架构

测试完成后结果页可包括：

1. **人格名**：如“暗中观察猫”。
2. **人格代码**：可做四字母或梗化编码，如 `SAFE-OBS`、`BOSS-CAT`。
3. **一句话总结**：最适合分享。
4. **雷达图**：亲人度、探索欲、安全敏感、能量值、边界感、领地感、情绪稳定、表达欲。
5. **典型行为**：3-5 条。
6. **人类翻译**：如果它是人，大概像什么性格。
7. **相处秘诀**：给人类的可执行建议。
8. **注意信号**：健康/压力提醒。
9. **朋友分享文案**：提高传播。

## 12. 可直接用于产品的猫人格底层分类

以下是一个可作为第一版类型系统的分类方式：先用八维评分找到主轴，再映射类型。

| 主轴组合 | 人格类型方向 |
|---|---|
| 高亲人 + 高表达 | 罐罐提款猫 / 人类训练师猫 |
| 高亲人 + 高稳定 | 贴贴外交官猫 |
| 高安全敏感 + 高观察 | 暗中观察猫 |
| 高探索 + 高能量 | 开箱工程师猫 |
| 高领地 + 高边界 | 家庭董事长猫 |
| 高能量 + 高冲动 | 午夜蹦迪猫 |
| 高边界 + 高敏感 | 飞机耳艺术家 |
| 低能量 + 高稳定 | 睡神哲学猫 |
| 高同类控制 + 高警觉 | 社交保安猫 |
| 高探索 + 高表达 | 人类训练师猫 |
