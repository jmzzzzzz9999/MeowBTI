# MeowBTI 猫格测试问卷 V2

更新时间：2026-05-26

用途：用于娱乐化猫格测试。题目基于猫咪常见行为场景设计，结果用于人格化表达，不用于医疗、训练或行为诊断。

## 设计原则

V2 版相对 V1 做了三处调整：

1. **选项不再只给一个结果加分**  
   同一个行为可能同时代表多个倾向。例如“门关了就叫”既可能是亲和表达，也可能是主权边界。因此每个选项可以给多个系列或猫格加分。

2. **减少直给猫格的题目**  
   不再让用户直接选择“像哪个猫格”，而是用具体场景、行为反应和假设情境来推断。

3. **加入条件分支题**  
   主问卷建议 16-18 题，条件题根据前面回答触发。这样测试更灵活，也避免所有用户都回答不适用的问题。

## 计分方式

每个选项后面的括号是加分建议。

格式说明：

- `亲和系 +1`：给系列加分。
- `贴贴外交官 +1`：给具体猫格加分。
- 同一个选项可以同时给多个系列和猫格加分。
- 如果某个选项是强指向，可以给 `+2`。

最终结果建议：

1. 先统计五大系列总分，得到主系列。
2. 在主系列内统计具体猫格，得到主猫格。
3. 跨系列高分猫格可作为“隐藏副猫格”。
4. 条件分支题只影响具体猫格和少量系列倾向，不建议权重过高。

## 推荐出题流程

### 基础流程

1. 用户完成 18 道主问卷。
2. 系统根据回答判断触发哪些分支。
3. 如果触发多个分支，最多展示 3 个分支题，避免题量过长。
4. 最终总题量建议控制在 20-23 题。

### 条件题触发优先级

如果同时触发多个分支，建议按以下优先级：

1. 触摸边界题：因为能明显区分三秒过载体、亲密防火墙、飞机耳艺术家。
2. 门/柜执念题：因为能区分门禁管理员、柜门黑客。
3. 夜间活跃题：因为能区分午夜蹦迪王、随机刷新猫、猎物模拟器。
4. 安定舒适题：因为能区分安定系内部结果。
5. 多猫题：只有用户明确多猫家庭时出现。

## 结果计算建议

### Feline Five 雷达图

结果页建议继续保留五大系列作为“分类阵营”，但量化展示改用 2017 年 PLOS ONE “Feline Five” 研究中的五个猫咪人格因子：

| 雷达维度 | 含义 | 页面表达建议 |
|---|---|---|
| 神经质 | 对刺激、变化、压力的敏感程度 | 高分可解释为更敏感、更警觉，不写成“脆弱” |
| 外向性 | 活跃、好奇、探索、玩耍和主动互动 | 高分代表更爱动、更爱探索 |
| 支配性 | 对资源、空间、路线或其他猫的控制倾向 | 高分代表主张强、领地感强 |
| 冲动性 | 行为突然性、不可预测性、过载或快速切换 | 高分代表更容易突然行动或反应强烈 |
| 亲和性 | 对人或同伴的友好、温和、合作和依恋 | 高分代表更亲近、更愿意建立连接 |

展示逻辑：

- 五大系列仍用于决定主猫格所属阵营。
- Feline Five 用雷达图展示该猫的气质轮廓。
- 雷达图分数可以由用户选项映射到对应猫格的 Feline Five 预设值，再按权重求平均。
- 文案应避免把高神经质、高支配性、高冲动性写成负面标签，最好翻译成“敏感雷达强”“主张清晰”“行动切换快”。

### 系列结果

统计五大系列总分：

- 亲和系
- 潜行系
- 探索系
- 主权系
- 安定系

最高分系列为主系列。若最高分与第二名相差不超过 2 分，可以显示为混合气质。

### 猫格结果

在主系列内部统计 5 个猫格分数，最高者为主猫格。

若跨系列某个猫格分数高于主系列最高猫格，可以作为“隐藏副猫格”展示。

### 平分处理

如果同系列内两个猫格平分：

1. 优先看该猫格是否在条件分支题里被加分。
2. 再看对应猫格强指向题 `+2` 的数量。
3. 若仍平分，显示“双猫格倾向”。
